# MoonTune

Редактор вокала от Moon Music Label: VST3 (Windows, macOS), Audio Unit (macOS), расширение ARA 2.
C++20 / JUCE 8 / CMake. Сборка описана в [BUILD.md](BUILD.md).

## Два способа работы

**ARA 2 (рекомендуется).** Studio One / Fender Studio Pro, Cubase, Logic (AU), Reaper и другие хосты с ARA:
выделить вокальное событие и выбрать «Edit with MoonTune» (ARA). MoonTune сам читает звук события,
записывать его через REC не нужно. Если сдвинуть или обрезать событие в DAW, ноты и правки переедут вместе с ним.
Клик по линейке времени в MoonTune ставит курсор DAW в это место и запускает воспроизведение.

**Без ARA (обычная вставка).** Включить **REC**, проиграть вокал, остановить. MoonTune нарисует ноты.

## Редактирование

Мышь работает одним инструментом:
- тянуть ноту вверх/вниз: высота (привязка к полутонам или к ладу, с Ctrl свободно);
- тянуть ноту влево/вправо: время (привязка к сетке, с Ctrl свободно);
- тянуть край ноты: длина;
- **ручки на выделенной ноте**: верхняя «~» задаёт глубину вибрато, нижняя «/» задаёт дрейф (как в VariAudio);
- пока держишь ноту, она звучит (**AUDITION**, когда DAW стоит);
- правый клик по ноте: сброс правок, разделить, объединить, октава, удалить;
- правый клик по клавише на линейке высот: добавить ноту в лад или убрать её из лада
  (например, G# в ля миноре). Сохраняется в проекте.

Панель навигации:
- **Engine**: выбор движка, см. ниже;
- **Grid**: сетка Off, 1/4, 1/8, 1/16, 1/32, 1/64, плюс триоли «3». Темп и размер берутся из DAW;
- **FOLLOW**: окно идёт за курсором DAW и при открытии показывает место курсора.
  Ручная прокрутка приостанавливает слежение до следующего Play;
- **AUDITION**: прослушивание нот при перетаскивании;
- **SHOW ALL**: показать весь вокал;
- обзорная полоса: весь вокал целиком. Клик по полосе переходит к этому месту.

**Воспроизведение из плагина:** PLAY/STOP или пробел; клик по линейке времени — метка, двойной клик —
играть оттуда, Alt+клик по ноте — с её начала. С ARA управляется DAW, без ARA MoonTune играет сам.

**Вдохи и согласные** («с», «ц» — фиолетовые, «к», «т», «п» — оранжевые, вдохи — бирюзовые) — отдельные объекты:
громкость ручкой Gain или инструментом GAIN (до тишины), правый клик — «Заглушить». Кнопка **BREATH** выделяет
все вдохи сразу. Высота их не меняется; согласная перед нотой двигается вместе с ней.
Атаки «б», «п», «д» и других взрывных проходят без обработки (≈15 мс), удар не смягчается (выключается PROTECT).

**Переходы между нотами:** ромбик на стыке нот или ручка Transition (0–500 мс). **Наклон ноты:** квадратная ручка
в углу ноты или Tilt.

**CORRECT PITCH** работает с живым просмотром: ноты и звук меняются сразу, пока двигаешь ползунки.
**Apply** оставляет результат, **Cancel** возвращает как было.

Нижняя панель для выделенных нот: Pitch, Vibrato, Drift, Formant, Level и Note EQ на 4 полосы
(выключен по умолчанию, включается касанием полосы).

**Processing**: отключение этапов для сравнения: PITCH, TIME, TIMBRE (сохранение тембра/формант),
EQ, PROTECT (защита согласных), CORR.

## Звуковые движки

Оба движка опираются на один и тот же анализ. Фаза основного тона голоса интегрируется по треку высоты,
и каждые 2 мс голос раскладывается на гармоники, привязанные к этой фазе (метод наименьших квадратов
по трём периодам). Так получается точное положение каждого периода без дрожания и ошибок октавы
и разделение на гармоники и остаток (дыхание, шум, согласные).

- **Harmony Clean** (по умолчанию). Гармоники заново синтезируются на новой высоте, их амплитуды и фазы
  берутся из спектральной огибающей, поэтому форманты (тембр) остаются на месте.
  Дыхание и шум идут отдельным слоем и сдвигаются вместе с голосом. Склеек звонкой части нет,
  значит нет «второго голоса» и щелчков.
- **True Voice**. PSOLA реальной формы волны по фазовой разметке периодов. Громкость следует за оригиналом.
- **Hybrid**. Результат True Voice, из которого оставлены только гармоники на новой высоте, плюс слой дыхания
  (вариант Z). Рендер примерно вдвое дольше.

Общее для обоих движков:
- меняется только смещение ноты, вибрато и переходы сохраняются;
- согласные не транспонируются;
- нетронутые места проходят бит в бит;
- после правки фаза голоса возвращается к оригиналу плавно (≤ 0,4 %, на слух незаметно),
  и следующая нетронутая фраза снова идёт бит в бит.

Рендер идёт в фоне. Анализ голоса кэшируется, пересчитываются только затронутые фразы:
правка одной ноты в 3-минутном полностью исправленном вокале занимает около 1 с на 2 ядрах.

## Ограничения (честно)

- Ноты и правки в режиме ARA хранятся в состоянии плагина (проект DAW), а не в ARA-архиве документа.
- ARA проверена тестовым хостом Celemony (все тест-кейсы, нарушений API нет) и автотестами.
  В реальных DAW её нужно проверить на слух и в работе.
- Сборка для macOS делается только в GitHub Actions. Подпись ad hoc (без Apple Developer ID),
  поэтому при первом запуске нужен `xattr -cr`, см. INSTALL-macOS.txt.


## Структура

```
Source/
  PluginProcessor.*        параметры, состояние, воспроизведение, прослушивание, импорт ARA
  PluginEditor.*           главное окно, панель навигации, слежение за курсором
  ARA/                     ARA 2 document controller
  Capture/                 запись (REC) и хранение вокала
  Analysis/                высота (YIN + Viterbi), ноты, фоновый анализ
  DSP/VocalRenderer.*      движки Harmony Clean и True Voice, кэш анализа и фраз
  DSP/RenderManager.*      фоновый рендер, передача в аудиопоток без блокировок
  DSP/TimeMap.*            карта времени с защитой согласных
  Model/                   ноты, Undo/Redo
  Music/                   тональности, свой лад, Analyze Key, Correct Pitch
  UI/                      сетка нот, обзор, панель нот с EQ, тональность, Correct Pitch
Tests/                     автотесты
```

## Лицензии зависимостей

- **JUCE 8**: AGPLv3 или коммерческая лицензия JUCE. Для закрытого продукта нужна коммерческая.
- **VST3 SDK** (в составе JUCE): условия Steinberg.
- **ARA SDK 2.2** (Celemony): Apache 2.0. Для использования логотипа и названия ARA
  смотрите условия Celemony.
- Алгоритмы (YIN, синусоидальная модель «гармоники + шум», PSOLA, RBJ-фильтры, профили Крумхансла)
  взяты из опубликованных методов и реализованы с нуля. Чужого кода нет.
